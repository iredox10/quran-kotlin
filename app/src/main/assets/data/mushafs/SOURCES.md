# Warsh and Qaloon offline editions

Publisher: King Fahd Glorious Quran Printing Complex (KFGQPC).
Publisher announcement: https://qurancomplex.gov.sa/الانتهاء-من-معالجة-بعض-الملحوظات-في-خط/
Unmodified font binaries and source records retrieved from the KFGQPC package mirror https://github.com/ibnhazm/KFGQPC on 2026-11-06.
The embedded font EULA explicitly grants use, copy and distribution free of cost; fonts must not be sold or modified. The full embedded licenses are included beside these data files.

Each narration contains 6,214 native Madani-numbered ayahs. This numbering is not Hafs numbering. No Hafs translation, audio, bookmark or tafsir key is assigned to these ayahs.
Rows with page ranges are displayed on both native pages, with their original text preserved. This is flowing Unicode text, not an exact printed-page facsimile.
Qaloon source JSON had trailing commas. Only JSON syntax was repaired for parsing; all field values, including Arabic and numbering, are unchanged.
All 114 surahs, consecutive native ayah numbers and pages 1–604 were checked. Every text character was checked against its paired font cmap.

`indopak_navigation.json`: derived from the embedded bookmarks in the exact verified original PDF above. All 114 surah starts use the printed page number (PDF one-based page minus 2); canonical surah display names come from the existing bundled chapter catalog. Bookmarks spelled `Sura 35` and `Surah 65` without a dot were parsed as authored, rather than omitted. Fatiha is printed page 2, Baqarah page 3 and Nas page 848. This index is independent of the Hafs 604-page lookup.

Native Home browsing indexes (`*_browse.json`) are reproducibly generated by `scripts/build-native-navigation.py`. Warsh/Qaloon chapter counts and juz starts come directly from the original corpus (`sura_no`, `jozz`, `page`). Their 60 hizb anchors are located uniquely in the native chapter text using a normalized consonantal concordance against the existing section starts; matching never substitutes Quran text or stores Hafs verse keys. Every native ayah ID and matching anchor is retained for auditing. Warsh 43:24 and Qaloon 3:15/43:24 require omitting the first word of the search anchor because the recitation differs; the following 40 normalized letters match uniquely. Short surah-initial ayahs use the authoritative native surah start. IndoPak juz starts and halves come directly from its original PDF's Juz/quarter bookmarks. The second hizb is printed page 16, rather than Hafs page 11. No shared Hafs page offsets are used for these editions.
